# NemoHackers.org (version 4)

The source of version 4 of the nemo hackers community site.

## Contents

- PHP pages for news, archives, FAQ, tools, network tools, music,
  projects, staff, feedback and uploads, with shared header, footer and
  menu includes.
- Perl CGI scripts in `CGI-BIN` for the news system.
- A hit counter, a mailing list, a Java IRC client (`JIRC`) and a
  phpBB forum.

## Tech

- PHP, Perl CGI, HTML and CSS

## Running

This is an archive of an old site. It needs a web server with PHP and
Perl CGI support to run.
